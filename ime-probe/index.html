IME probe

A diagnostic page for input-method bug reports. Two identical <textarea> fields, one directly on the page and one inside an iframe like the MDN interactive examples, both logging every input event.

Nothing leaves your machine. This page is a single static file with no network access; it only displays what it observes. Note that the log contains every character you type into the fields, so type test characters rather than real text if you plan to paste the log into a public bug report.

1. Textarea on the page

2. Textarea inside an iframe

How to run it

  1. Hold the base key, tap the leader key, then release both.
  2. Release the base key first, then tap the leader key.
  3. Repeat both after pressing Alt+Space (close the window menu with Esc).
  4. Then click around the field with the mouse only, without typing.

Step 1 versus 2 shows whether the leader key cycles or inserts a space. Red lines in step 4 mean text arrived with no keystroke behind it. Purple lines mean a key was pressed but never released, which is what a compositor-side window menu does when it grabs the keyboard.

Measurements

Derived from the events themselves. This page cannot read your input-method configuration, so the leader key, overlay placement, addon version and compositor still have to be stated by hand in a bug report.
